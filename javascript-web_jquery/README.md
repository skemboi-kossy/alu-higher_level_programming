# JavaScript - Web jQuery

Scripts for selecting and changing HTML elements, handling click events and making GET requests with jQuery.
Checked with `semistandard *.js --global $`.

## Files
- `0-script.js`: changes header color with `document.querySelector` (no jQuery)
- `1-script.js`: changes header color with jQuery
- `2-script.js`: header turns red when `DIV#red_header` is clicked
- `3-script.js`: adds the class `red` to the header on click
- `4-script.js`: toggles the header class between `red` and `green`
- `5-script.js`: adds an `<li>Item</li>` to `UL.my_list` on click
- `6-script.js`: updates the header text on click
- `7-script.js`: fetches a Star Wars character name
- `8-script.js`: lists all Star Wars movie titles
- `9-script.js`: fetches and displays a translation of "hello"
