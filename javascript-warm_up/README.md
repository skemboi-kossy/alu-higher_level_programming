# JavaScript - Warm up

Beginner JavaScript scripts covering variables, loops, functions, arguments, objects and modules.

## Requirements
- Node 14.x on Ubuntu
- Code checked with semistandard
- All files start with `#!/usr/bin/node` and are executable

## Files
- `0-javascript_is_amazing.js`: prints "JavaScript is amazing"
- `1-multi_languages.js`: prints 3 lines
- `2-arguments.js` to `5-to_integer.js`: work with command line arguments
- `6-multi_languages_loop.js` and `7-multi_c.js`: loops
- `8-square.js`: prints a square
- `9-add.js`, `10-factorial.js`, `11-second_biggest.js`: functions and math
- `12-object.js`: updating an object
- `13-add.js`: exporting a function
