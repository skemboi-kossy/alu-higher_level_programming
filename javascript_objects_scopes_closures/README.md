# JavaScript - Objects, Scopes and Closures

Scripts covering classes, inheritance (extends and super), closures and scope.
Run with Node 14, style checked with semistandard.

## Files
- `0-rectangle.js` to `4-rectangle.js`: building up a Rectangle class
- `5-square.js`, `6-square.js`: Square classes that inherit from Rectangle
- `7-occurrences.js`: counts occurrences in a list
- `8-esrever.js`: reverses a list without `reverse`
- `9-logme.js`: logs with a running count (closure over a module variable)
- `10-converter.js`: converts a number to another base
